# 💪 FitLog (Solo) — แอปสะสมนาทีออกกำลังกาย แบบแยกเครื่อง

**เวอร์ชัน localStorage** — ข้อมูลของแต่ละคนเก็บอยู่ในมือถือของตัวเอง ไม่ sync กัน
✅ ไม่ต้องมี Firebase · ไม่ต้องใส่ config · ใช้งาน offline ได้ 100%

## ต่างจากเวอร์ชันครอบครัว (Firebase) ยังไง
| | Solo (ชุดนี้) | ครอบครัว (Firebase) |
|---|---|---|
| ข้อมูล | ในเครื่องตัวเอง | แชร์กัน real-time |
| ตั้งค่า | ไม่ต้องทำอะไร | ต้องใส่ Firebase config |
| Offline | ได้เต็มรูปแบบ | บันทึกได้ sync ทีหลัง |
| ข้อควรระวัง | ล้าง browser data = ข้อมูลหาย → ใช้ปุ่ม Export | - |

## ฟีเจอร์เพิ่มในเวอร์ชันนี้
- 🔥 **Streak** — นับวันออกกำลังกายติดต่อกัน
- 📊 สรุปสัปดาห์นี้ + ยอดสะสมทั้งหมด
- ⬇⬆ **Export / Import (.json)** — สำรองข้อมูลกันหาย และใช้ย้ายเครื่องได้

## ติดตั้ง
1. สร้าง repo GitHub (Public) เช่น `fitlog` — ใช้ repo เดียวแชร์ให้ทุกคนได้ เพราะข้อมูลแยกตามเครื่องอยู่แล้ว
2. อัปโหลด 5 ไฟล์ไว้ที่ root: index.html, manifest.json, sw.js, icon-192.png, icon-512.png
   ⚠️ อัปโหลดไอคอนผ่าน GitHub web บน PC (กัน Chrome มือถือ rename เป็น `-1`)
3. Settings → Pages → Deploy from branch → main / root
4. แต่ละคนเปิดลิงก์เดียวกัน แล้ว **Add to Home Screen** — ต่างคนต่างมีข้อมูลของตัวเอง
5. แก้ไฟล์ทีหลังเมื่อไหร่ → bump cache ใน sw.js (`fitlog-solo-v2` → `v3`)

## หมายเหตุ
- ลิงก์เดียวกัน ทุกคนใช้ได้ แต่ข้อมูลไม่ปนกัน (localStorage แยกตาม browser/เครื่อง)
- แนะนำ Export สำรองเดือนละครั้ง กันเผลอล้างข้อมูล browser

## อัปเดต v2
- 📷 รูปโปรไฟล์ — แตะวงกลมบนการ์ดสีน้ำเงินเพื่อถ่าย/เลือกรูป (ย่ออัตโนมัติ 256px เก็บใน localStorage, รูปติดไปกับ Export/Import ด้วย)
- 💪 เพิ่มกิจกรรม: วิดพื้น, ซิทอัพ, สควอท, แพลงกิ้ง
- cache เป็น fitlog-solo-v2 แล้ว

## อัปเดต v3 — แชร์ลงโซเชียล 📤
- **แชร์สรุปเดือนนี้** — ปุ่มในการ์ด "ภาพรวม" สร้างรูปการ์ด 1080×1080 (รูปโปรไฟล์ + ชื่อ + นาทีสะสม + ครั้ง + streak + % เป้าหมาย)
- **แชร์รายรายการ** — ปุ่ม 📤 ในประวัติแต่ละแถว (เช่น แชร์ผลวิ่งวันนี้)
- กดแล้วเปิด **share sheet ของมือถือ** → เลือก Facebook / LINE / IG / Messenger ได้เลย
- ถ้าเปิดบน PC หรือ browser ไม่รองรับ share จะดาวน์โหลดเป็น PNG ให้อัตโนมัติ
- cache เป็น fitlog-solo-v3 แล้ว

## อัปเดต v4 — สะสมน้ำหนักตัว ⚖️
- การ์ด "น้ำหนักตัว" — บันทึกน้ำหนัก (กก.) เป็นช่วงๆ, บันทึกวันเดียวกันซ้ำ = อัปเดตทับ
- แสดงน้ำหนักล่าสุด + เทียบครั้งก่อน (▼ เขียว = ลด, ▲ แดง = เพิ่ม) + รวมเปลี่ยนแปลงจากเริ่มต้น
- กราฟเส้นแนวโน้ม 20 จุดล่าสุด + ประวัติ 6 รายการ (ลบได้)
- น้ำหนักล่าสุดโชว์ในการ์ดแชร์สรุปเดือนด้วย (ถ้ามีข้อมูล)
- ข้อมูลน้ำหนักติดไปกับ Export/Import อัตโนมัติ
- cache เป็น fitlog-solo-v4 แล้ว

## อัปเดต v5
- การ์ดแชร์รายรายการ (📤 ในประวัติ) แสดง ⚖️ น้ำหนักล่าสุด เป็นช่องที่ 4 ด้วย (ถ้ามีข้อมูลน้ำหนัก)
- ปรับขนาดตัวเลขสถิติอัตโนมัติเมื่อมี 4 ช่อง ไม่ให้ชนกัน
- cache เป็น fitlog-solo-v5 แล้ว
